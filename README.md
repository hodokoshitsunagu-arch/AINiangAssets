## 介绍的设定边界

DeepSeek、GPT、Claude、Gemini、Grok、Qwen、Kimi、GLM 八位介绍现采用 **v2 审核稿（2026-11-04）**，保留背景、人设／性格、口头禅、道具／武器、朋友关系及对应视频链接。MiniMax 仍保留此前项目原创介绍，未纳入本次 v2 更新。

v2 仅以 [AIGCー泠绡（3707046645992165）](https://space.bilibili.com/3707046645992165/upload/video) 与 [冬冰（44748304）](https://space.bilibili.com/44748304/upload/video) 在 2026-11-04 核查时“最新发布”的各15条视频为样本。前者覆盖 2026-09-29 至 2026-11-01，后者覆盖 2026-10-16 至 2026-11-02；冬冰主页中的合作投稿也计入，实际主上传者包括桃莉鸭与沉默寡言佰佰佰。

30条均已进行人工联系图核查：泠绡长片约每6秒取样、短片约每1秒取样，冬冰约每15秒取样。此为抽帧研究，尚未完成全片连续审阅或逐句对白转录。性格归纳是对样本行为的有限解释；没有依据的完整身世、固定武器和反复口头禅保留未确认状态。不同作者的日常、异世界及盘点片段分别看待，不拼成统一正史，也不以旧版设定补证。

文字属于同人作品观察与审核文案，不代表模型品牌的官方人格或性能。Q版是成年角色的漫画化身。上游立绘的可见外观优先，视频场景道具不自动成为立绘中的固定武器。研究截图、裁剪与原片仍在本地，本次更新仅发布文案。
